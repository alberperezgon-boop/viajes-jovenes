# Viajes independientes para jóvenes: investigación y propuesta

Proyecto de startup del programa de emprendimiento joven. Esta carpeta es a la vez **bóveda de Obsidian** y **repositorio de Git**: todo lo que se investiga, se decide o queda pendiente vive aquí, para no repetir trabajo ni perder contexto.

> **Eje del proyecto:** las dificultades de los jóvenes de 16 y 17 años para organizar viajes sin padres, profesores ni monitores. Corner y las demos del equipo son referencias para explorar soluciones, no el objetivo.

## Cómo se etiqueta la fiabilidad

Toda afirmación lleva una de estas etiquetas:

| Etiqueta | Significado |
|---|---|
| `VERIFICADO` | Fuente oficial o primaria leída directamente, con fecha |
| `OFICIAL-INDIRECTO` | La fuente es oficial, pero se leyó a través del resumen de un buscador; releer antes de citarla en una presentación |
| `SECUNDARIA` | Prensa, blogs, agregadores, foros |
| `CONOCIMIENTO PREVIO` | Se sabía de antes; no se ha comprobado en una fuente durante esta investigación |
| `INFERENCIA` | Deducción razonada a partir de hechos; puede estar equivocada |
| `HIPÓTESIS` | Suposición que hay que validar con datos |

Regla: **no se presenta como viable un viaje, un proveedor o una norma que no esté `VERIFICADO`.**

## Cómo trabajar

1. Antes de investigar algo, búscalo en [Evidencias](<02 Registro/Evidencias.md>) y en [Dudas pendientes](<02 Registro/Dudas pendientes.md>).
2. Cada hallazgo nuevo es una evidencia (`E-xx`) con fuente, fecha y etiqueta, y se enlaza a las hipótesis que afecta (`H-xx`).
3. Cada decisión (`D-xx`) dice qué evidencia la sostiene.
4. La [Bitácora](<02 Registro/Bitácora.md>) resume cada sesión en tres líneas.
